# AirPlay Video Receiver

Turn the Raspberry Pi's HDMI output into an AirPlay screen-mirroring receiver.
Video and audio from an iPhone, iPad or Mac show up on the TV connected to the Pi.

It wraps [UxPlay](https://github.com/FDH2/UxPlay), with GStreamer rendering
straight to the display. No desktop or X server is needed. See the
Documentation tab for setup and options.
